================================================================================
TROUBLESHOOTING
================================================================================

Images not loading?
→ Check NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME in Vercel settings
→ Verify image URLs in Supabase start with https://res.cloudinary.com
→ Restart dev server after adding env vars

Emails not sending?
→ Check RESEND_API_KEY is correct
→ Check Resend dashboard for delivery logs
→ Verify RESEND_FROM_EMAIL is set
→ Check spam folder

Order not creating?
→ Check console for API errors
→ Verify auth token exists
→ Check /api/orders endpoint
→ Check Supabase connection

Admin dashboard 403?
→ Make sure user is logged in as admin
→ Check user record has admin privileges
