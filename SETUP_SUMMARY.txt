╔═══════════════════════════════════════════════════════════════════════════╗
║  🆘 QUICK TROUBLESHOOTING                                                 ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Images Not Loading?
  └─ Check NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME in Vercel
  └─ Restart dev server (npm run dev)
  └─ Verify Supabase URLs start with https://res.cloudinary.com

  Emails Not Arriving?
  └─ Check RESEND_API_KEY is set correctly
  └─ Check spam folder
  └─ Check Resend dashboard for errors

  Order Checkout Fails?
  └─ Check browser console for errors
  └─ Verify auth token exists
  └─ Check Network tab for API responses

  Admin Can't Access /admin?
  └─ Make sure logged in as admin user
  └─ Check user has isAdmin: true in database
